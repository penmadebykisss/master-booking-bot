# Бот записи для мастера или салона

[![CI](https://github.com/penmadebykisss/master-booking-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/penmadebykisss/master-booking-bot/actions/workflows/ci.yml)

Telegram-бот, который принимает записи вместо администратора: клиент сам выбирает услугу, день и свободное время,
оставляет телефон — мастеру приходит уведомление, клиенту — напоминания. Подходит мастерам маникюра, парикмахерам,
бровистам, массажистам, косметологам, репетиторам — всем, кто работает по записи.

**Что умеет**
- Запись в свободные окна: рабочие часы, перерывы, выходные, длительность услуги, шаг сетки — двойная запись невозможна.
- Напоминания клиенту за 24 и за 2 часа (настраивается) с кнопкой «Не смогу — отменить».
- «Мои записи»: клиент видит свои записи и сам отменяет не позже чем за N часов.
- Мастеру: уведомление о каждой новой записи и отмене, сводки «Сегодня / Завтра / Неделя».
- Цены, адрес, как добраться — одной кнопкой.
- Вопросы клиентов: отвечает ИИ по вашим данным (цены, адрес, правила) и ничего не выдумывает; без ИИ — вопрос уходит мастеру.

Всё, что относится к конкретному мастеру (услуги, цены, график, адрес, ответы на частые вопросы), — в одном файле
`config.yaml`. Новый клиент = новый конфиг, код не меняется.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Узнайте свой Telegram ID (например, у @userinfobot) — туда будут приходить уведомления о записях.
3. `cp config.example.yaml config.yaml` и заполните услуги, цены, график, адрес.
4. `cp .env.example .env` и впишите `BOT_TOKEN` и `ADMIN_IDS`. Для ответов ИИ — `AI_API_KEY` (OpenRouter или любой
   OpenAI-совместимый сервис).

Docker:

```bash
docker build -t master-bot .
docker run -d --name master-bot --restart always --env-file .env \
  -v $PWD/config.yaml:/app/config.yaml -v $PWD/data:/data -e DB_PATH=/data/bookings.sqlite3 master-bot
```

Или напрямую (Python 3.10+):

```bash
pip install -r requirements.txt
python -m bot.main
```

Бот работает через long polling: белый IP, домен и HTTPS не нужны.

## Команды мастера

Кнопки «📋 Сегодня / Завтра / Неделя» или команды `/today`, `/tomorrow`, `/week` — видны только тем, чей ID указан в `ADMIN_IDS`.

## Тесты

```bash
pip install -r requirements.txt -r requirements-dev.txt && pytest -q
```

Проверяются сетка времени, перерывы, конец рабочего дня, занятые окна, «не раньше чем через час», выходные,
повторная проверка окна перед записью, напоминания и отмена.
